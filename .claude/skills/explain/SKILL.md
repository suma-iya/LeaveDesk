Explain the file or feature I name:
1. Its purpose in one sentence.
2. The runtime flow step by step: HTTP request → middleware → handler → service → repository → DB, and back.
3. Why it's written this way, and one alternative I could mention.
4. Ask me 3 questions to check I understood. Wait for my answers before grading them.
Use simple language. Never modify code in this skill.
